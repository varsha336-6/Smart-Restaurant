# 🍽️ Smart Restaurant - QR Table Ordering

A **Computer Graphics** project developed using **Python, Pygame, and PyOpenGL**. This project simulates a smart restaurant where users can explore a 3D restaurant environment and experience a QR-based table ordering concept.

---

## 📖 Project Overview

The Smart Restaurant project demonstrates how Computer Graphics can be used to create an interactive restaurant environment. Users can navigate inside the restaurant, view tables, and understand the concept of QR code-based ordering in a realistic 3D scene.

---

## ✨ Features

- 🍽️ 3D Restaurant Environment
- 📱 QR Table Ordering Concept
- 🪑 Interactive Restaurant Layout
- 🎮 Keyboard Navigation
- 🖥️ Realistic Computer Graphics Scene
- 🚀 Smooth Rendering using OpenGL
